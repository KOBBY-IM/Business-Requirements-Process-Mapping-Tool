How It Works

Three steps to a full analysis

1

Describe the Problem

Write a plain-English description of the current broken process — who does what, where it fails, and what better looks like.

2

Claude Analyses It

Claude reads your description and returns a structured JSON object: a process model, requirements list, and stakeholder data.

3

Download the Outputs

Export your process map as an SVG for presentations, and your requirements and stakeholders as CSV for spreadsheets.

Privacy note: Your API key and problem description are sent directly from your browser to the Anthropic API. They are never stored, logged, or routed through any intermediate server. This tool has no backend.
